# Урок 4 · Підключення CSS — шпаргалка

## Головні концепції

### 1. Підключення
```html
<head>
  <meta charset="UTF-8">
  <title>Сайт</title>
  <link rel="stylesheet" href="style.css">
</head>
```
- `rel="stylesheet"` — «це файл стилів». `href` — шлях до файлу, як `src` у img.
- Файл у підпапці css → `href="css/style.css"`.
- Один файл стилів на весь сайт. `style="…"` у тегів та `<style>` — не використовуємо.

### 2. Правило
```css
селектор {
  властивість: значення;
}
```
- Властивість і значення — через **двокрапку**, наприкінці обов'язково **крапка з комою**.
- Коментар: `/* текст пояснення */`.

### 3. Селектори
- За тегом: `p { }` — усі абзаци сторінки. Назва тегу пишеться без `< >` і без крапки.
- Група: `h1, h2 { }` — одне спільне правило для кількох тегів.

### 4. Колір і фон
- `color` — колір **тексту**. `background-color` — колір **фону**.
- Три записи одного кольору: `tomato` · `#ff6347` · `rgb(255, 99, 71)`.
- Текст і фон обов'язково мають бути контрастними для гарної читабельності.

### 5. Шрифт
| Властивість | Приклад | Що робить |
|---|---|---|
| `font-family` | `Georgia, serif` | сімейство шрифту + запасний |
| `font-size` | `18px` | розмір літер |
| `font-weight` | `bold` / `normal` | насиченість (жирність) |
| `font-style` | `italic` | курсивне накреслення |
| `line-height` | `1.6` | висота рядка (інтерліньяж) |
| `text-align` | `center` | вирівнювання по центру |
| `text-decoration` | `none` | прибрати підкреслення |

### Шрифти та іконки з інтернету
**Google Fonts** — fonts.google.com, фільтр Language → **Cyrillic**.
1. Get font → Get embed code → скопіювати `<link>` у `head` **вище за** style.css.
2. У CSS: `font-family: "Montserrat", sans-serif;` — назва буква в букву, із запасним шрифтом.

**Font Awesome** — fontawesome.com/icons, фільтр **Free**.
1. У `head`: `<link rel="stylesheet" href="https://cdnjs.cloudflare.com/ajax/libs/font-awesome/7.0.1/css/all.min.css">`
2. У розмітці: `<i class="fa-solid fa-mug-hot"></i>` — тег копіюємо з сайту.
3. Іконка — це шрифт: `i { color: …; font-size: …; }`.
   `fa-solid` — суцільні залиті, `fa-regular` — контурні, `fa-brands` — офіційні логотипи.

### 6. Успадкування та каскад
- Колір і шрифт від `body` успадковують усі теги всередині.
- Два правила сперечаються за одну властивість → перемагає **нижнє за порядком**. Інші властивості об'єднуються.
- Стиль не спрацював? Відкриваємо **F12 → Elements → Styles**.

## Винятки та підводні камені
1. Посилання не бере колір від body: у `a` власний синій колір за замовчуванням від браузера. Пишемо окремо `a { color: … }`.
2. Заголовки не беруть розмір і жирність від body: у `h1–h6` є власні дефолтні стилі браузера.
3. Забули `;` — ламається не лише поточний рядок, а й наступне оголошення після нього.
4. CSS не показує повідомлень про помилки: некоректна властивість чи значення просто ігнорується браузером. Шукаємо в DevTools.
5. Число й одиниця вимірювання пишуться разом: `40px`, не `40 px`. У `line-height` можна без одиниць: `1.6`.
6. Назва шрифту, що містить пробіли, береться в лапки: `"Times New Roman"`.
7. Крапка перед назвою — це селектор класу: `.h1` ≠ `h1`.
8. Файл у папці: `href="css/style.css"`. Назва повинна збігатися буква в букву.
9. `style="…"` в HTML сильніший за файл стилів — саме тому ми не використовуємо інлайн-стилі.
10. Змін не видно? Збережіть файл (Ctrl+S) і оновіть сторінку в браузері (F5).
